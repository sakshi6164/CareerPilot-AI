# 🚀 CareerPilot AI v2.5

CareerPilot AI is an AI-powered career assistant built with Streamlit and OpenRouter AI. It helps students and professionals optimize their resumes, prepare for interviews, generate cover letters, analyze GitHub and LinkedIn profiles, and receive personalized career guidance.

---

## ✨ Features

### 📄 Resume Analyzer
- ATS Score Analysis
- Skill Gap Detection
- Resume Strengths & Weaknesses
- Keyword Analysis
- AI Suggestions
- PDF Report Generation

### 📝 Resume Builder
- ATS-Friendly Resume Creation
- AI Resume Rewriting
- Professional Formatting
- Download Resume

### 💼 Job Matcher
- Resume vs Job Description Matching
- Match Percentage
- Missing Skills
- AI Recommendations

### ✉ AI Cover Letter Generator
- Personalized Cover Letters
- Company Specific
- ATS Friendly
- Download Support

### 🎯 Career Roadmap
- Personalized Learning Path
- Skills to Learn
- Certifications
- Project Suggestions

### 🎤 Interview Preparation
- HR Questions
- Technical Questions
- Behavioral Questions
- AI Mock Interview

### 🔗 LinkedIn Analyzer
- Profile Review
- Headline Suggestions
- Recruiter Optimization
- Keyword Improvement

### 💻 GitHub Analyzer
- Repository Analysis
- Contribution Review
- Portfolio Feedback
- Project Suggestions

### 🤖 AI Career Coach
- Career Guidance
- Learning Recommendations
- Resume Advice
- Placement Preparation

### 📊 Dashboard
- ATS Analytics
- Career Progress
- Skill Tracking
- Resume History
